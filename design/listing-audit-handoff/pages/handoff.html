For Claude Code. Next.js App Router, server components and server actions. Full spec: HANDOFF.md · styles: globals.css — both delivered alongside this canvas; give them to Claude Code with the export.

Porting rules

  1. Every link: use data-route as the real href; *.dc.html hrefs are prototype-only.
  2. Form actions are the real endpoints; keep button name/value.
  3. Styles come from globals.css; drop each artboard's local style block.
  4. All names, ₹ figures and SKUs are sample data; bind them to the DB.
  5. Only two client islands: CopyButton (data-copy-target) and AiToggle (submit on change, with a <noscript> Save button).
  6. Every queue card has id="iss_xxxx"; redirects and links end in #iss_xxxx to keep the scroll position.
